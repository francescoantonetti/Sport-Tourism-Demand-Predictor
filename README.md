# Sport Tourism Demand Predictor — Streamlit Dashboard

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

The dashboard reads all project CSVs from the local `data/` folder.

## Pages
- Overview
- Forecast Performance
- City Explorer
- Geographic Map
- Event Impact
- Model & Data Quality

## Theme
The visual theme mirrors the previous SBL dashboard family: navy sidebar, light grey-blue background, white KPI cards, orange accent and pale-blue information panels.
